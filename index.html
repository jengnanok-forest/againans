👨‍🏫 教師端：建立錯題任務

題目與解答在同一個檔案也可以，只傳這一份即可

可以是有題目的解析卷，也可以只有答案

或：直接貼上答案文字（選填）
支援哪些格式？
  • 檔案：.docx（含圖片、表格）、.xlsx / .csv 答案表（欄位：題號｜答案｜解析）、.txt、.html；舊版 .doc、PDF 請先另存成 .docx
  • 題目 + 解答在同一檔：題後有「答案：③」、行內「（③）」、題後「【答案】」，或最後附一整段答案表
  • 解答卷有題目：「1. ③　說明」「1.（2分）③」「第1題 答案③」
  • Excel 答案表：第一列為「題號、答案、解析」，解析欄可留空；小題題號可寫 11-1 或 11(1)；想分大題可加一欄「題型」（如 選擇題、是非題）
  • 解答卷只有答案：「1.③ 2.② 3.①」、「答案：③②①」、「1~5 ③②①④④」、「1 A 2 C 3 B」、直式或橫式答案表
  • 答案符號：①②③④、A B C D、1 2 3 4、○ ╳ × ✕ O X、對 錯
  • 填充題、問答題等無法自動批改的題目會自動略過
